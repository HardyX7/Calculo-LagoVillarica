PROCEDIMIENTOS DE CÁLCULO DEL PROYECTO
MODELO DEL LAGO VILLARRICA

Este documento contiene solamente el procedimiento matemático: datos,
fórmulas, sustituciones, operaciones y resultados.

NOTA SOBRE LOS DATOS DE GEOGEBRA

En los archivos del proyecto no están guardadas las coordenadas originales de
todos los puntos seleccionados en GeoGebra. Sí están guardados la escala, los
límites de los tramos y los polinomios cúbicos obtenidos a partir de esos
puntos. Por eso, el procedimiento numérico comienza con esos datos.

1. DATOS OBTENIDOS DEL MODELO DE GEOGEBRA
==========================================================================

Escala:

1 unidad del plano = 1 km real.

Factor lineal:       s   = 1.
Factor de área:      s²  = 1² = 1.
Factor de volumen:   s³  = 1³ = 1.

Por tanto, las unidades del modelo se convierten directamente en km, km² y
km³.

Dominio horizontal del lago:

[a,b] = [0; 22,5].

Puntos donde cambia el polinomio:
x₀ = 0

x₂ = 6,47

La curva superior se llama f(x) y la curva inferior se llama g(x).

Procedimiento utilizado para obtener un polinomio desde cuatro puntos de
GeoGebra:

P(x) = Ax³ + Bx² + Cx + D.

Para cuatro puntos (x₁,y₁), (x₂,y₂), (x₃,y₃) y (x₄,y₄), se sustituye cada
punto:

A(x₁)³ + B(x₁)² + C(x₁) + D = y₁
A(x₂)³ + B(x₂)² + C(x₂) + D = y₂
A(x₃)³ + B(x₃)² + C(x₃) + D = y₃
A(x₄)³ + B(x₄)² + C(x₄) + D = y₄

Al resolver estas cuatro ecuaciones se obtienen A, B, C y D. Este proceso se
repitió para cada uno de los cinco tramos superiores y los cinco inferiores.

7. MODELO ELÍPTICO UTILIZADO EN EL PROYECTO
==========================================================================

Datos guardados en el programa:

Centro: (h,k) = (11,25;5,6).
Semieje horizontal: a = 11,25 km.
Semieje vertical:   b = 5,6 km.

Eje mayor = 2a = 22,5 km.
Eje menor = 2b = 11,2 km.

Ecuación:

[(x-11,25)²/(11,25)²] + [(y-5,6)²/(5,6)²] = 1.

Área de la elipse:

A_elipse = πab
         = π(11,25)(5,6)
         = 197,920337176 km².

Volumen del modelo elíptico con profundidad constante de 0,12 km:

V_elipse = A_elipse·0,12
         = 197,920337176·0,12
         = 23,750440461 km³.

Área elíptica obtenida directamente por integral:

y_superior = k+b√[1-(x-h)²/a²].
y_inferior = k-b√[1-(x-h)²/a²].

y_superior-y_inferior = 2b√[1-(x-h)²/a²].

Los límites son:

x_izquierdo = h-a = 11,25-11,25 = 0.
x_derecho   = h+a = 11,25+11,25 = 22,5.

A_elipse = ∫(0 a 22,5) 2(5,6)√[1-(x-11,25)²/(11,25)²] dx.

Sustitución:

u = (x-11,25)/11,25,
dx = 11,25du.

Cuando x=0, u=-1.
Cuando x=22,5, u=1.

A_elipse = 2(11,25)(5,6)∫(-1 a 1)√(1-u²)du.

Como:

∫(-1 a 1)√(1-u²)du = π/2,

entonces:

A_elipse = 2(11,25)(5,6)(π/2)
         = π(11,25)(5,6)
         = 197,920337176 km².

==========================================================================
8. VOLUMEN DEL ENUNCIADO CON SECCIONES SEMICIRCULARES
==========================================================================

Este cálculo corresponde al enunciado que usa ejes de 23 km y 11 km y
secciones transversales semicirculares. Es un procedimiento distinto del
volumen con profundidad constante de la sección 6.

Eje mayor = 23 km, por tanto:

a = 23/2 = 11,5 km.

Eje menor = 11 km, por tanto:

b = 11/2 = 5,5 km.

Ecuación de la elipse centrada en el origen:

x²/(11,5)² + y²/(5,5)² = 1.

Despeje de y:

y²/(5,5)² = 1-x²/(11,5)².

y = ±5,5√[1-x²/(11,5)²].

El diámetro vertical de cada sección es:

d(x) = y_superior-y_inferior
     = 5,5√[1-x²/(11,5)²]-[-5,5√[1-x²/(11,5)²]]
     = 11√[1-x²/(11,5)²].

Área de una semicircunferencia de diámetro d:

A_seccion = (1/2)πr²,
r = d/2.

Por tanto:

A_seccion(x) = (1/2)π[d(x)/2]²
             = (π/8)d(x)².

Sustituyendo d(x):

A_seccion(x) = (π/8){11√[1-x²/(11,5)²]}²
             = (121π/8)[1-x²/(11,5)²].

Los extremos horizontales son:

x_izquierdo = -a = -11,5.
x_derecho   =  a =  11,5.

El volumen es:

V = ∫(-11,5 a 11,5) A_seccion(x)dx

  = (121π/8)∫(-11,5 a 11,5)[1-x²/(11,5)²]dx.

Antiderivada:

∫[1-x²/a²]dx = x-x³/(3a²).

Entonces:

V = (121π/8)[x-x³/(3(11,5)²)] desde -11,5 hasta 11,5.

Evaluación en x=11,5:

11,5-(11,5)³/[3(11,5)²]
= 11,5-11,5/3
= 23/3.

Evaluación en x=-11,5:

-11,5-(-11,5)³/[3(11,5)²]
= -11,5+11,5/3
= -23/3.

Resta de los extremos:

23/3-(-23/3) = 46/3.

Por tanto:

V = (121π/8)(46/3)
  = 2783π/12
  = 728,587696245 km³.

Redondeando:

V = 728,588 km³.
